Недавние задачи

С чего начать

  1. Данные → нарежьте большой файл на классы (rust / проза / чат…), при необходимости возьмите выборку N ГБ и соедините нужные файлы в один.
  2. Обучение → «Новая модель», выберите размер и файл → «Старт». «Стоп» сохраняет чекпойнт; в любое время «Продолжить» с того же места.
  3. Чат → проверьте, что умеет модель.
  4. Слияние → объедините несколько моделей одинакового размера или нарастите глубину (stack).

1. Нарезка большого файла по классам

Делит смешанный файл на rust / проза / чат / диалоги… Сгенерированный код и мусор отбрасываются. «Только отчёт» ничего не пишет — сначала посмотрите, что получится.

Только отчёт (dry-run)
Сохранять сгенерированный код

2. Выборка N ГБ из большого файла

Равномерно по всему файлу кусками (по 1 МБ) — получается уменьшенная копия с тем же составом.

3. Соединение файлов в один обучающий

Добавьте файлы и веса. Без «итогового размера» вес = сколько раз взять файл (0.5 — половина, 2 — дважды). С итоговым размером веса — пропорции (7:2:1 → 70/20/10 %). Для нескольких маленьких моделей запускайте соединение несколько раз с разными наборами.

4. StarCoderData (parquet) → текст

5. Нарезка на непересекающиеся куски (для нескольких моделей)

Режет большой файл на N кусков с РАЗНЫМ содержимым. «chunks» — куски равномерно из всего файла (одинаковое качество); «contiguous» — каждый кусок из своей области файла. Размер куска можно ограничить: для веток из этапа «Слияние» хватает 0.3–0.5 ГБ на кусок.

Слияние моделей

  
  

  

  

  

  

  
Для «grow» выберите ровно одну модель. «Пустые» слои дают точно ту же модель, что была (проверка: val «ДО фазы» при дообучении должен совпасть с val исходной); затем дообучайте — новые слои начнут учиться.

  

  

  

  
Слияние работает на процессоре и в ОЗУ. Усреднять имеет смысл только модели одной архитектуры с общим происхождением (одна инициализация). После stack модель нужно дообучить («залечить»).

 
Эксперимент: ветки от общей базы → слияние → проверка

  
Одной кнопкой: для каждого куска данных создаётся ветка от базы и дообучается коротко (малый LR, чтобы ветки остались «рядом»), затем ветки сливаются (среднее и TIES от базы), после чего у базы, веток и слитых моделей измеряется val на данных базы и печатается итоговая таблица. Делается в одном окне «Логи» — можно уйти и вернуться; «Стоп» сохраняет текущую ветку.

Метрика кода: доля синтаксически корректного Rust

  
Модель продолжает N начал функций/структур; считается, сколько результатов закрылись скобками и разобрались парсером Rust (нужен rustfmt). Бит/байт этого не показывает. Для сравнения моделей запускайте с одинаковыми N и длиной. При N=40 разброс ±14 п.п. (95% ИС), поэтому для сравнений берите N≥200 (≈10 минут).

# План исследований HashNet

Правило: идём по пунктам, каждый тест короткий и измеряется на одном эталоне. Что не работает — убираем из основной программы до конца серии тестов. Новые механизмы (после серии) живут в отдельном репозитории — отправной точке следующих исследований.

Эталон: 3.4M (d256, L4, h8, seq512, batch 8, lr 0.0016, 20000 шагов, seed 1) = **1.061 бит/байт** (1024 окна val, шум 0.002). Результаты — в [RESULTS.md](RESULTS.md).

## Сделано
Studio; слияние/рост; точный val и шум; сравнение с архиваторами; свип lr; форма при одном бюджете; хэш-эмбеддинги n-грамм (минус, убрано).
